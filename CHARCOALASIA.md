# Project Detail – Charcoal Asia

## Overview
Charcoal Asia is a **premium export brand website** dedicated to showcasing and promoting eco-friendly charcoal briquettes for the international market. The platform emphasizes product quality, sustainability, and global partnerships, while providing a professional digital presence for potential buyers and distributors.

## Technical Stack
- **Frontend:** Next.js (React-based framework) for server-side rendering and SEO advantage  
- **Styling:** TailwindCSS + custom typography aligned with industrial/eco-friendly branding  
- **Backend:** Node.js + Express (for product catalog API and inquiries)  
- **Database:** PostgreSQL for product, client, and order data management  
- **Deployment:** Deployed on Vercel with global CDN edge delivery  
- **Version Control:** GitLab CI/CD pipeline for build, test, and deploy stages  

## Key Features
1. **Product Catalog Showcase**
   - Dynamic product listing (briquette types, packaging, specifications)  
   - High-resolution imagery optimized with WebP  

2. **Global Inquiry System**
   - Contact form with backend validation  
   - Integration with SMTP/SendGrid for lead capture and partner communication  

3. **Multilingual Support**
   - English as the default, with options to expand into Asian and European languages  
   - i18n routing in Next.js  

4. **SEO & Marketing**
   - Schema.org structured data for products  
   - Blog section for sustainability articles and industry updates  
   - Integrated Google Analytics and Meta Pixel  

5. **Performance**
   - Image lazy loading  
   - Static page pre-rendering with ISR (Incremental Static Regeneration)  
   - Lighthouse optimization (90+ target across all metrics)  

## Workflow
- **Planning:** Brand guideline alignment (dark industrial theme + eco-green accents)  
- **Design:** UI crafted in Figma, emphasizing clean typography and impactful visuals  
- **Development:** Feature-based branching in GitLab (catalog, contact, blog)  
- **Testing:** SEO audits, cross-device responsiveness testing  
- **Deployment:** Automatic build and release pipeline on Vercel  

## Challenges & Solutions
- **International Market SEO:** Solved with multilingual keywords and schema markup  
- **High-Resolution Product Images:** Balanced quality with performance using next/image + WebP  
- **Lead Capture Security:** Implemented reCAPTCHA + backend sanitization to prevent spam

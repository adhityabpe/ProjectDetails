# Project Detail – Service AC Landing Page

## Overview
The Service AC project is a **basic landing page website** created for a local air conditioning service business. The goal is to provide a simple yet professional online presence, highlight services, capture leads, and build trust with potential customers.

## Technical Stack
- **Frontend:** HTML5, CSS3, JavaScript (vanilla)  
- **Styling:** Bootstrap 5 for responsive layout and quick component usage  
- **Hosting:** Shared hosting (cPanel/Apache) for cost efficiency  
- **Version Control:** Git (local repo with periodic backups)  

## Key Features
1. **Landing Page Structure**
   - 4 sections: Hero, Services, About/Why Choose Us, Footer (contact info + CTA)  
   - Mobile-first responsive design  

2. **Lead Capture**
   - Contact form with email forwarding (via PHP mailer)  
   - WhatsApp click-to-chat integration for instant inquiries  

3. **SEO Optimization**
   - Local SEO keywords (e.g., “Service AC Bandung”, “AC maintenance”)  
   - Optimized meta description + OpenGraph for social sharing  

4. **Performance**
   - Optimized assets (WebP images, minified CSS/JS)  
   - Lightweight footprint, targeting <1.5s load time on mobile  

5. **Trust Elements**
   - Testimonials and service guarantees  
   - Clear pricing structure and service categories  

## Workflow
- **Planning:** Defined 4-section structure and wireframe in Figma  
- **Development:** Implemented modular sections in Bootstrap grid system  
- **Testing:** Mobile responsiveness on Android/iOS, desktop cross-browser checks  
- **Deployment:** Uploaded via FTP to hosting environment  

## Challenges & Solutions
- **Low Budget Constraints:** Solved by using lightweight tech stack (no complex backend)  
- **Fast Delivery:** Delivered within 1-week timeline using pre-built Bootstrap components  
- **Mobile Usability:** Adjusted button sizes and CTA placement for thumb reach zones
